Principles

  1. One step, one idea. Each step moves only its own money, then stops. The card explains it in two sentences.
  2. Every token has a payer, a payee and a badge. Cobalt is REAL, amber dashed is SIMULATED, ink is a message with no money.
  3. The ledger answers "who holds what". Balances tween as tokens land. Any agent opens its own ledger.
  4. One red path. Only the Under-gate refund turns an edge red.
  5. The diagram is the UI, the slide and the video. Draw it once.
